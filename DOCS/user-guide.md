# ESDR3_Player. Руководство пользователя

## Что это

Плеер IQ-записей ExpertSDR3. Открывает файлы `ExpertSDR3_IQ_Freq_<Гц>_Date_<дата>_Time_<время>.wav`,
показывает спектр и водопад всей записанной полосы, позволяет настроиться на любую станцию
внутри неё и слушать её в модах CW, USB, LSB, AM, FM. Работает на macOS, Windows и Linux.

Частота дискретизации, центральная частота (DDS) и время старта берутся из служебного чанка
`esdr` в файле, поэтому шкала показывает настоящие частоты, а метки на водопаде настоящее время записи.

## Установка

- **macOS**: откройте `.dmg`, перетащите `ESDR3_Player.app` в «Программы». Сборка подписана
  ad-hoc, при первом запуске macOS может показать предупреждение: откройте через
  правый клик → «Открыть».
- **Windows**: распакуйте `.zip` в любую папку и запустите `ESDR3_Player.exe`.
- **Linux**: сделайте `.AppImage` исполняемым и запустите. Нужен `libfuse2`.

## Окно

- **Верхняя панель**: Open, Play/Pause, Stop, Loop, скорость (0.5x–4x), имя файла, время
  записи в текущей позиции, позиция и длительность.
- **Панорама**: сверху спектр в дБ полной шкалы, под ним шкала частот в кГц, ниже водопад с
  метками времени записи слева. Жёлтая линия это VFO, полупрозрачная полоса это окно фильтра.
- **Правая панель**: приёмник, спектр, водопад, язык.
- **Внизу**: ползунок позиции и состояние.

## Мышь на панораме

| Действие | Результат |
|---|---|
| Клик | VFO на эту частоту (шаг 10 Гц, с Shift 1 Гц) |
| Колесо | Зум вокруг курсора, от всей полосы до 1 кГц |
| Перетаскивание фона | Сдвиг видимой части полосы |
| Перетаскивание линии VFO | Плавная перестройка |
| Перетаскивание края окна фильтра | Изменение полосы фильтра |
| Двойной клик | Вся полоса записи |

## Клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Пауза / продолжить |
| ← → | Перемотка ±5 с, с Shift ±60 с |
| Home | В начало |
| ↑ ↓ | VFO ±10 Гц, с Shift ±100 Гц |
| M | Тихо / звук |
| + − 0 | Зум ближе, дальше, вся полоса |
| Cmd/Ctrl+O | Открыть файл |

Пока курсор стоит в поле Width или Pitch, односимвольные клавиши из таблицы не срабатывают:
нажатия уходят в набор числа.

## Приёмник

- **Частота**: цифры над кнопками мод. Наведите курсор на разряд и крутите колесо: шаг равен
  весу этого разряда, младший даёт 1 Гц. За пределы записанной полосы настройка не уходит.
- **Моды**: CW, USB, LSB, AM, FM. Полоса запоминается отдельно для каждой моды.
- **Width**: полная ширина фильтра. Для CW, AM и FM фильтр симметричен вокруг несущей, для
  USB и LSB начинается в 200 Гц от несущей.
- **Pitch**: тон CW, 300–1200 Гц. Несущая станции, на которой стоит VFO, звучит этим тоном.
- Width и Pitch вводятся и с клавиатуры: щёлкните по полю справа от ползунка и наберите число.
  Enter применяет, Esc отменяет. Значение вне допустимых границ не принимается.
- **AGC**: Off (ручное усиление), Fast, Slow.
- **Volume**, **Mute**, **Output** (звуковое устройство). При смене устройств в системе
  вывод переключается сам.
- Звук идёт только на скорости 1x. На других скоростях панорама работает, звука нет.

## Спектр и водопад

- **FFT**: 4096–32768. Больше точек, уже бин, медленнее реакция.
- **Average**: сглаживание спектра во времени.
- **Top/Bottom**: границы шкалы спектра в дБ.
- **Auto range**: водопад сам подбирает пол и потолок по уровню шума строки. Снимите
  галочку, чтобы задать границы вручную.
- **Palette**, **Height** (доля водопада), **Clear waterfall**.

## Файлы

- Записи любой длины читаются потоково, память не расходуется.
- Файл, который ExpertSDR3 пишет прямо сейчас, можно открыть: при достижении конца плеер
  подхватывает дописанное.
- Обычные IQ-WAV других программ (PCM 16/24/32 бит, float32) тоже открываются, но без
  центральной частоты: шкала будет от нуля.

## Командная строка

```
ESDR3_Player [файл.wav] [--play] [--mute] [--lang en|ru]
```

## Если что-то не так

- Нет звука: проверьте Output и Mute, посмотрите строку «Audio … underruns». Растущее число
  пропусков означает, что компьютер не успевает; уменьшите FFT или частоту кадров.
- Станция звучит не на том тоне в CW: поставьте VFO точно на линию станции, перетаскивая
  жёлтую линию.
- Файл не открывается: сообщение об ошибке появится красным в правой панели.
